## Information and Privacy

</div>

> [!WARNING]
> Features you enable may take a few seconds to load. Please wait for them to finish loading before trying to use them. If the website stops working, gets stuck while loading or rendering, or shows a “Page isn't responding” error, please contact me as soon as possible. The issue may be caused by the extension's source code, and details about what happened can help me find and fix the problem.

> [!NOTE]
> Results from the [ScanRepo](https://www.scanrepo.dev/scan/github/7io5/nexus) confirm this.
> Nexus is 100% open source and runs entirely in your browser. It does not use a server or backend, and it does not collect telemetry or analytics. Your actions and activity stay on your own device and are not sent to a unknown server. You can review the source code to see how the extension works and what it does. However, features may still have bugs, so please report any problems you encounter.

## Installation

</div>

<table align="center" width="100%">
  <tr>
    <td width="52" align="center"><strong>1.</strong></td>
    <td align="left">
      <strong>Install a userscript manager</strong>
      <br><br>
      Install <a href="https://www.tampermonkey.net/">Tampermonkey</a> or <a href="https://violentmonkey.github.io/">Violentmonkey</a>
    </td>
  </tr>
  <tr>
    <td align="center"><strong>2.</strong></td>
    <td align="left">
      <strong>Enable allow userscripts instructions</strong>
      <br><br>
      <strong>Chromium browsers</strong> (Chrome 138+, Edge, Brave, Opera): either right-click the Tampermonkey icon → <em>Manage extension</em> → enable <strong>Allow user scripts</strong>, <em>or</em> enable <strong>Developer mode</strong> at <code>chrome://extensions</code>.
      <br><br>
      See the <a href="https://www.tampermonkey.net/faq.php?ext=iikm&q=Q209">Tampermonkey FAQ</a> for more information.
    </td>
  </tr>
  <tr>
    <td align="center"><strong>3.</strong></td>
    <td align="left">
      <strong>Install Nexus</strong>
      <br><br>
      Click <a href="https://raw.githubusercontent.com/7io5/nexus/main/main.user.js">here</a> to install or update.
    </td>
</table>

> [!TIP]
> Tampermonkey checks for updates automatically. If you want to force one, either open the Tampermonkey dashboard and press **Check for updates** on the userscript or click the **Installation link** to update.
