<h2>Information and Privacy</h2>

**Features you enable may take a few seconds to load. Please wait for them to finish loading before trying to use them. If the website stops working, gets stuck while loading or rendering, or shows a “Page isn't responding” error, please contact me as soon as possible. The issue may be caused by the extension's source code, and details about what happened can help me find and fix the problem.**

**Nexus is 100% open source and runs entirely in your browser. It does not use a server or backend, and it does not collect telemetry or analytics. Your actions and activity stay on your own device and are not sent to a unknown server. You can review the source code to see how the extension works and what it does. However, features may still have bugs, so please report any problems you encounter.**

<h2>Installation</h2>

<p>1. Install <a href="https://www.tampermonkey.net/">Tampermonkey</a> or
   <a href="https://violentmonkey.github.io/">Violentmonkey</a></p>

<p>2. Enable allow userscripts instructions:<br>
   <strong>Chromium browsers</strong> (Chrome 138+, Edge, Brave, Opera):
   either right-click the Tampermonkey icon → <em>Manage extension</em> → enable
   <strong>Allow user scripts</strong>, <em>or</em> enable <strong>Developer mode</strong> at
   <code>chrome://extensions</code>.<br>See the <a href="https://www.tampermonkey.net/faq.php?ext=iikm&amp;q=Q209">Tampermonkey FAQ</a> for more information.</p>

<p>3. Click <a href="https://raw.githubusercontent.com/7io5/nexus/main/main.user.js">here</a>
   to install or update</p>

<p>Tampermonkey checks for updates automatically. If you want to force one, either open the Tampermonkey dashboard and press <strong>Check for updates</strong> on the userscript or click the <strong>Installation link</strong> to update.</p>
